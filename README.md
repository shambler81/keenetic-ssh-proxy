# SSH Proxy для Keenetic

Приложение запускает OpenSSH на роутере и создаёт локальный SOCKS5-прокси. Штатный клиент Keenetic подключается к этому SOCKS, а политики и маршруты настраиваются средствами KeeneticOS. Управление SSH-профилем — через отдельную веб-страницу приложения.

```text
Устройство в сети → выбранный маршрут Keenetic → Proxy → 127.0.0.1:1080
                                                             ↓
                                      SSH на роутере → SSH-сервер → интернет
```

**[Пошаговая установка и настройка](docs/INSTALL.ru.md)** — подготовка накопителя, Entware, SSH-сервера, приложения и маршрутов, проверка и устранение ошибок.

## Совместимость

Готовый архив `dist/keenetic-ssh-proxy-mipsel.tar.gz` собран для Linux MIPSel soft-float. Бинарный файл и веб-панель запускались на Keenetic Hero 4G KN-2310 с KeeneticOS 5.1.8 и ядром 4.9; пользователь сообщил, что настроенное подключение заработало. Перед установкой на другую модель проверьте архитектуру: архив **не подходит автоматически для MIPS big-endian, ARM или ARM64**.

Приложение поддерживает SSH по паролю или закрытому ключу, необязательный сертификат OpenSSH, проверку ключа сервера, подключение, отключение, автозапуск туннеля и переподключение. Индикатор «Подключено» означает, что SSH открыл локальный SOCKS, а не что конкретные сайты уже проверены.

SSH `-D` передаёт TCP, но не UDP: QUIC, некоторые звонки и другие UDP-сервисы могут работать иначе. Профиль SSH и секреты хранятся на накопителе в файлах с доступом для root, **без шифрования**. Панель использует отдельный пароль и самоподписанный HTTPS-сертификат.

Исходники на Go не требуют сторонних Go-зависимостей. На роутере используются Entware и его пакеты `openssh-client`, `openssh-client-utils`, `wget-ssl` и `ca-bundle`.
